# Media Studio setup

Needs Chrome or Edge, recent (File System Access API, WebCodecs). Nothing else: no install, no server, no network.

1. Clone: `gh repo clone leandromeiramedeiros/MediaStudio`
2. Double-click `MediaStudio.vbs`. It opens an app window with its own profile (`%LOCALAPPDATA%\MediaStudio\window`), so its folder permission and settings stay apart from your browser.
3. Choose the library folder on the welcome screen, e.g. the NVIDIA capture folder `Videos\NVIDIA\...`. Grant access when asked.
4. Optional: desktop shortcut. Right-click `MediaStudio.vbs` > Send to > Desktop (create shortcut).

**Check:** the header pill shows the folder name and your captures appear in Library.

If the launcher says Chrome or Edge is missing, install one of them.
